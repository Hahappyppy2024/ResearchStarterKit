# 雾蓝 · 荷塘（完整网站，空白数据）

这是本机实际网站的完整公开源码副本，不再是简化静态模板。

```sh
python run.py
```

需要 Python 3.11+，常规页面使用标准库；不要求 Node.js。入口为 http://127.0.0.1:8869/#daily。公开副本使用 8866—8870 端口，与原站的 8766—8770 分开。

页面、阅读任务、笔记、分类、项目、课程管理、小鱼放生等交互保留；数据库、私人论文与进度、项目记录、博客文章和课程内容均为空。第一次运行才在 `app/local-data/` 创建自己的数据库，该目录不会进入 Git。私人 News／Idea 模块按此前要求不发布，普通 Blog 保留。

arXiv 自动更新需要网络及本地服务运行；`python run.py --preview --no-browser` 可关闭本次预览的自动采集。Zotero 导入需要使用者自行连接、手动操作。已有诗词目录不带出；未导入时显示空目录。PPT 预览／编辑等可选功能仍需要 Windows、PowerPoint 或相关转换工具，不会附带课程 PPT。PDF 阅读使用随仓库提供的 PDF.js。

GitHub 仅保存源码。GitHub Pages 不能运行 Python／SQLite；要运行这套完整网站，请下载后使用上述命令，或另外配置合适的应用服务器。当前服务保持回环绑定及同源访问检查。
