# ResearchStarterKit · 雾蓝 · 荷塘

一个空白起步的科研桌面风格模板。淡雾蓝、荷塘水彩、七朵莲花、圆角卡片与留白，适合个人阅读与研究空间。

**[进入网站源码](sites/mist-blue-lotus/)** · [目录说明](docs/REPOSITORY.md) · [公开内容边界](docs/PUBLIC-RELEASE.md) · [English](README_EN.md)

## 目录

| 目录 | 用途 |

## 预览网站

在仓库根目录运行 Python 3：

```sh
python -m http.server 8080 --bind 127.0.0.1
```

打开 **http://127.0.0.1:8080/sites/mist-blue-lotus/**。无需数据库或安装前端依赖。也可以把 `sites/mist-blue-lotus/` 作为静态网站目录部署；资源采用相对路径，兼容 GitHub Pages 项目子路径。仓库根 `index.html` 指向该网站。

## 目前包含什么

- 双语导航、荷塘页首与页尾、三栏圆角布局和移动端排版。
- 浏览器本地待办、手动阅读清单、随手笔记。
- 问题／方法／证据／局限的阅读结构展示。
- 基础课程、科研课程、自研课程仅保留空白入口，**不包含课程内容**。

这是可独立预览的**公开风格模板**，不是本机完整科研系统的在线副本。自动 arXiv 采集、PDF 阅读任务、数据库及小鱼放生联动仍属于本地系统；网页明确标注展示范围。

## 数据边界

本次发布未复制本机数据库、课程材料、News／Idea 内容、个人笔记、论文清单、项目数据或进度。新网站首次打开为空白。访客自己输入的内容只保存到自己的浏览器 localStorage，不会提交 GitHub 或其他服务器；清除浏览器数据会丢失这些内容。

发布前运行：

```sh
python scripts/check_public_release.py
```

原仓库历史保留；目录整理不重写 Git 历史。历史提交中的既有公开文件不因本次整理而从历史中消失。
