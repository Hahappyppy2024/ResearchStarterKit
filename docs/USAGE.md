# ResearchStarterKit 中文使用指南

[返回首页](../README.md) | [English Guide](USAGE_EN.md)

## 一、下载与文件放置

1. 打开 ResearchStarterKit 的 GitHub 仓库主页。
2. 点击 **Code → Download ZIP**，下载并解压；也可以使用 Git 克隆仓库。
3. 将解压内容放在自己选择的本地位置，建议不要直接放在系统文件夹里。
4. 打开文件夹，先阅读 `README.md`，再检查实际提供的脚本、页面和依赖说明。

> **注意**：如果你拿到的是单独的“README 文档包”，它**不包含应用代码**；应将包内 `README.md`、`README_EN.md` 和 `docs/` 文件夹复制到真实的 **Git 仓库根目录**，而不是在根目录中再套一个同名文件夹。

## 三、推荐的新手学习流程

### 第 1 周：确定主题和阅读目标

**目标**：将模糊兴趣变成可执行的阅读任务。

- 用一句话写下自己希望理解的问题。
- 列出 5–10 个检索关键词（可中英双语）。
- 从综述、基础工作或权威教材开始，建立初步知识地图。
- 不必追求一次读懂全部论文。

### 第 2 周：分层阅读与结构化记录

对每篇论文，至少记录以下内容：

| 维度 | 需要回答的问题 |
| --- | --- |
| 基本信息 | 标题、作者、年份、来源、链接或 DOI |
| Research Problem | 论文解决什么问题？这个问题为什么重要？ |
| Method | 核心方法和主要假设是什么？ |
| Evidence | 用什么实验、数据或理论支持结论？ |
| Limitations | 哪些条件下可能失败？哪些结论证据不足？ |
| My Questions | 我还有哪些疑问？应阅读哪篇相关工作？ |

推荐阅读次序：**先摘要、引言和结论 → 看方法与关键图表 → 按需要深入实验和细节**。不要求所有论文一开始都逐字精读。

### 第 3 周：跨论文比较

选择 3–5 篇相近研究，比较它们的任务定义、假设、方法、实验设置与局限。尝试回答：它们之间的主要差异是什么？证据足以支持作者结论吗？

### 第 4 周：总结与下一步规划

将笔记整理为一页主题综述：

- 已知问题与常见解决路径
- 已有工作的共同点和分歧
- 尚未解决或证据不足的问题
- 下一阶段需要补充的背景知识、论文和实验技能

**每周持续复盘**：这周学到了什么？还不确定什么？下一周要验证什么？

## 四、如何使用写作方法和 AI Slides

- **科研方法资源**：把内容当作检查清单，而不是机械套用的规则；尤其要检查研究问题是否明确、实验能否支持结论。
- **学术写作资源**：先建立论证主线，再优化英语表达；论文每一节都应服务于研究问题。
- **AI 模型 Slides**：推荐“概念 → 简化例子 → 数学/结构 → 代码或实验 → 自己解释”的学习顺序。
- **资料尚未上传时**：请以 GitHub 中实际存在的文件为准，不要把计划中的内容误认为已提供。

## 五、数据、安全与常见问题

**问：不熟悉编程可以使用吗？**  
文献阅读流程和方法资料可以直接参考；本地应用是否需要编程环境，取决于最终发布的安装步骤。

**问：是不是完全离线？**  
不能仅凭“本地”判断。使用外部模型、检索接口或 API 时可能需要网络并发送数据。

**问：能把自己的 PDF 和笔记提交到公共仓库吗？**  
不建议。公开前检查版权、隐私以及 Git 跟踪文件，尤其是数据库、配置文件、密钥和用户内容。

**问：如何反馈错误？**  
到项目的 **Issues** 页面，附上所用操作系统、操作步骤、预期结果、实际结果和可以公开的报错内容。不要附上私密数据或密钥。
