# 完整公开副本的边界

## 保留

以本机当前完整网站源码为基础，保留页面、共享样式、服务端模块与前端交互。原先位于私有目录中的最终荷塘 CSS 单独作为视觉源文件迁入 `app/web-shared/mist-blue-lotus.css`。荷塘背景、莲花、星空、小鱼及每周状态小猫均作为显式选择的界面素材复制，不复制周围的私人目录。

## 清空／排除

不复制任何本机数据库、`local-data` 目录、课程 PPT／PDF、上传文件、课程记录、论文快照、阅读答案、博客、项目、放生进度或私人 News／Idea 实现。学者静态个人清单置空。课程种子不带入。诗词个人工作簿与目录不带入，未导入时使用空目录。

## 必要适配

- 全部本地端口改为 8866—8870，避免连接原站。
- 私人绝对路径改为副本自己的相对数据目录。
- 原依赖仓库外 Node 服务的旧启动项改为仓库内完整页面，不要求外部私人仓库。
- 缺少私人素材／数据时改为空状态；不伪造论文和进度。
- News／Idea 页签与私有实现移除；普通 Blog 保留。
- 在公开副本创建空库所需的 schema 初始化保留。

## 验收

运行完整副本的统一首页、课程、Blog 与核心接口；确认课程、博客、论文、项目和放生列表为空。回归测试覆盖阅读奖励去重、分类、对比、主题分发、PDF 与项目论文关联。检查 Git 候选文件，没有数据库、课件、私人模块或原站端口引用。

这不是浏览器静态演示；GitHub Pages 不能运行 Python／SQLite。使用者下载后运行 `python run.py`。保留已有 Git 历史，不声称清除旧历史中的既有内容。
