# 公开内容边界

## 本次新增网站

只包含手写 HTML/CSS/JS 与三份经过明确选择的视觉素材：荷塘水彩图、七朵莲花 SVG、珍珠小鱼 SVG。没有导出本机的 HTML 渲染结果、localStorage、SQLite、论文、课程、截图或私人笔记。

公开网站使用独立 localStorage 键，与本地科研系统的数据键分开。不连接本机 8766—8770 服务，不发起采集任务，不调用模型，不上传访客内容。

课程仅显示三种课程的空白分类。News 与 Idea 的实现及内容均不加入新网站。

## 原有工具

从 GitHub 已公开的 HEAD 整理，不从本机未提交修改中批量复制。课程生成器、旧个人学者追踪 JSON 和原页面截图从本次工作树移除；旧版本仍可在 Git 历史中恢复。基础模块的自动示例种子设为空，避免首次启动自动生成内容。

## 检查方法

`python scripts/check_public_release.py` 检查当前发布文件的允许目录、数据库／密钥／缓存／课程材料路径、静态站资源引用、外部脚本和本机 API 引用。该检查针对当前工作树，不声称审计或删除远端全部历史。

提交采用显式暂存目录，禁止 `git add` 本机工作副本或复制 `local-data`。发布网站前请自行确认素材授权范围；本次未额外授予仓库统一开源许可证。
