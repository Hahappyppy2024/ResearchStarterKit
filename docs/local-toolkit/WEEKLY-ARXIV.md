# 每周 arXiv 合集

入口：`http://127.0.0.1:8769/#arxiv`，独立页 `/arxiv.html`。

- ISO 周，周一至周日；默认上一完整周，本周为进行中。
- 新论文按 API `published` 的原始日期归档。这是第一版提交处理日期，**不是公开公告日**；旧数据只有日期，不能恢复公告时间。
- `updated` 晚于 `published` 的条目同时进入对应周的版本更新区，不重算为新论文。更新区主要来自已有每日检索，不代表全站所有修订。
- 首次存入的题录／摘要快照保留；新增方向归属可合并。原文和摘要阅读器按同一论文 ID 访问当前文献，可能比快照更新。
- 每日检索继续将已采集数据归档。8766 服务运行时，07:35 后每 30 分钟检查上一周：每天最多一次成功检索，失败可重试。设备关机期间不会运行，下次启动补查。
- 每个研究方向用 `submittedDate` 日期范围分页查询，间隔至少 3.2 秒；只保存元数据和链接。全部方向成功才标记独立检索完成，失败保留原合集与错误提示。
- 页面“补全本周检索”可重试选中周。历史仅覆盖本机已有记录或成功检索的周，不代表完整历史数据库。
- 初始精选按方向覆盖产生 10 篇候选，未依据作者姓名推断知名度。可以增删精选（最多 50 篇），并写周总结。
- 周总结与精选保存在 `data/weekly-arxiv.sqlite`；未提交草稿另留在浏览器。阅读状态沿用浏览器现有存储，按论文 ID 跨周去重。
- 不下载 PDF，不改变 Zotero 暂停状态。备份时保留该 SQLite 文件、原有每日 JSON、文献库及浏览器导出记录。

验证：`python -m unittest test_weekly_arxiv test_local test_topics`；`node web/reading-history.test.mjs`；`node web/todos.test.mjs`。
