## Zotero 连接

已检测到 Zotero 8.0.4，安装在 `D:\Zotero`，本机通信已开启。
本机服务通过 Zotero 官方 Connector 接口保存题录，通过本地 API 回读验证。
不需要 Zotero 云端 API key，也没有直接修改 Zotero SQLite 数据库。
Codex 可在本工作区运行下列命令操作此连接；这不是给所有聊天安装全局 MCP 插件。

```powershell
python D:\000_workwork\research-local\local_app.py status
python D:\000_workwork\research-local\local_app.py sync
python D:\000_workwork\research-local\local_app.py daily
```

保存目标为个人“我的文库”，遇到群组库选中状态会暂停导入。
条目带 `会议/CVPR`、`年份/2025`、`CVPR/2025`、`主题/Object Detection` 等标签。
这些是标签分类，不会改动你的既有文件夹。会议全量记录包含“其他”主题，未因关键词不匹配而删除。
主题由标题和可用摘要自动初筛，不是官方会议 track。作者影响力未知时明确标待核实。

PDF 保存为官方链接，不批量下载全文。首批日程中的 8 篇附有小型 PDF 入口页面，其余条目附 linked_url。
精读时打开 PDF 链接，在 Zotero 中添加下载的文件即可。
导入按来源 ID、原始 URL、规范化标题去重。单一论文在不同会议版本之间的合并仍建议人工核实。
导入会保留已有同名条目，不覆盖你原来的笔记或作者信息。
Zotero 本身是否云同步遵循你原有设置，本程序不改变它。

## 每日与会议更新

Windows 任务 `ResearchLocal-DailyArxiv`：北京时间 07:30。
按五个方向查询 arXiv 最新更新，每条查询取前 100 条，保留近 7 天；源请求间隔至少 3 秒。
该范围是明确的自动检索窗口，不承诺收录全站所有相关结果。
电脑需开机；错过触发后由 Windows 在可用时补跑。脚本会在需要时启动 Zotero。
失败记录在 `data/last-job.json` 与网页状态中，不把失败标成当天成功。
会议目录由 `conference_sources.py` 获取；每来源状态见网页“各会议抓取完整性与来源状态”。
尚未发布或访问失败的会议不会以虚构论文填充。ICCV 非举办年份不添加假目录。

## 数据与迁移

- `data/library.sqlite`：本机论文题录、Zotero 导入状态。
- `data/YYYY-MM-DD.json`：每日清单。
- `data/conferences.json`：官方会议元数据和抓取覆盖状态。
- 网页打卡、笔记、阅读状态：当前浏览器 localStorage，可分别导出/导入备份。

原云端域名与 localhost 是不同浏览器存储空间。请从旧网页导出打卡/笔记和阅读状态，再在本地网页导入。
此目录不上传到 Sites。旧云端网页/云端定时任务是另一套资源，不会因启动 localhost 自动消失。

### 半小时时间选择和子任务

新增待办与编辑安排使用整点、半点下拉框；选择开始时间时，空白或无效的结束时间自动设为半小时后，最晚可到当天 24:00。旧记录的分钟时间保留，需用户主动选择后才改变。新增任务继续按固定时间切分原安排。

每个日程或 Todo 均可展开不计时的子任务，支持添加、编辑、完成、删除与撤销。子任务按日期和父任务保存；分段日程共用同一份清单，子任务进度独立于父任务完成状态。导出和导入备份包含子任务。

### 将论文放进任务

每日论文卡片的「加入任务」可选择当前日期的已有任务，创建不计时的论文子任务；也可单独建为无时间待办，再编辑整点／半点阅读时段。同一父任务下的同一论文不会重复添加。论文任务保留中英摘要与原文入口，备份导入导出保留论文关联。任务打卡和论文列表的已读标记分别保存。

### 每篇论文的六项阅读清单

论文卡片、日程论文子任务和独立论文待办都可通过「阅读清单」打开六项问题：problem、solution、为何有效、limitation、如何改进、延展问题。每项提供回答框和独立完成勾选，进度显示为 0–6 项。回答及完成状态以论文 ID 为键自动保存在当前浏览器（跨日期、跨任务共用），与原来的论文笔记和已读状态分开。该清单暂不包含在日程导出备份中。
