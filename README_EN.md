# ResearchStarterKit · Mist Blue & Lotus Pond

A standalone, buildless research workspace theme with mist-blue surfaces, watercolor lotus artwork, rounded panels and bilingual navigation.

See [Chinese README](README.md), [site source](sites/mist-blue-lotus/), and [public-release boundaries](docs/PUBLIC-RELEASE.md).

Run `python -m http.server 8080 --bind 127.0.0.1` from the repository root, then open `http://127.0.0.1:8080/sites/mist-blue-lotus/`.

The public site starts empty. Tasks, reading links and scratch notes are stored only in the visitor's browser. Course content and the owner's local databases, records, News and Ideas are excluded. Automated collection and full reading workflows are not simulated by this static theme.

Original public toolkit sources now live in `toolkit/`, tests in `tests/`, and historical documentation in `docs/`. Git history is preserved.
